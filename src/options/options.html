高级偏好设置

💾 更改即时生效并自动保存
🎨 外观主题与个性化
界面外观主题
选择控制台与弹窗的色彩方案。支持跟随操作系统日夜模式自动交替，或固定使用夜间/白天模式。
界面显示语言
选择控制台与弹窗的显示语言，支持根据浏览器语言自动适配。
🛡️ 拦截统计与隐私策略
统计规则拦截命中次数
当访问命中已配置的防护规则并自动删除历史时，是否累加记录拦截次数。关闭后进入极致无痕状态，不保存任何命中计数。
重置所有规则拦截计数
一键将当前所有防护规则的累计拦截次数清零，不影响规则本身的启用状态与拦截逻辑。
📦 规则备份与数据迁移
导出规则备份 (JSON)
将当前配置的所有域名与路径防护规则导出为 JSON 文件，用于多设备同步、版本备份或朋友共享。
导入规则备份 (JSON)
选择先前导出的 JSON 备份文件恢复规则。支持选择“合并导入”或“覆盖替换原有规则”。
清空所有防护规则
彻底清空本地存储中所有的防护规则。此操作无法撤销，建议在清空前先导出 JSON 备份。
🕶️ 临时无痕模式与默认策略
默认临时无痕时长
在弹窗快捷开启“临时无痕模式”时，预设的倒计时生效时长。到期后将由后台闹钟自动恢复常规防护。
快捷转规则默认类型
在历史检索与清理中点击“删除记录并将搜索词加入防护规则”时，缺省的规则类型识别模式。
添加规则时默认清理历史
在控制台添加规则或在弹窗快捷加入防护时，默认是否勾选“同时清理已有历史记录”。开启则默认删除，关闭则默认仅加入规则并保留历史。
⚡ 海量历史检索性能与安全
历史记录加载步长
控制历史记录每次检索加载的条目数量。数值越小内存占用越低，数值越大翻页浏览越流畅。
大量删除并发节流限制
控制重型历史清理时的执行节奏与并发度。推荐保持“智能自适应”，可根据不同浏览器内核自动调整性能并防止界面卡顿。
全部清空前二次确认
针对匹配结果点击“全部清空”前，是否弹出系统警告对话框二次确认，防止误触误删。
🔔 界面交互与反馈提示
操作提示 Toast 停留时长
控制界面右下角操作反馈与提示浮层的展示时长。

⚠️ 修改并发节流限制警告

非必要请勿修改此设置！HistorySentry 默认采用“智能自适应”，已针对不同浏览器底层架构进行了极致调优。手动更改并发数可能导致以下问题：

🔒
Firefox 数据库锁死：Firefox Places SQLite 采用单写锁机制。并发过高极易引发 database is locked 报错，导致浏览器严重卡顿甚至无响应。
⚡
性能消耗与卡顿：过高并发会导致浏览器进程与磁盘 I/O 瞬间飙高，在进行大批量删除时可能引起正常网页浏览掉帧或短暂假死。
🛡️
强烈建议保持“智能自适应”，HistorySentry 会自动匹配当前浏览器的最佳性能与稳定性。
